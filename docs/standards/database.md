# Database Standards

Coding conventions for SQL and database schema development.

## SQL Style

- **Quotes**: Use double quotes for identifiers, single quotes for strings
- **Keywords**: Use UPPERCASE for SQL keywords (`SELECT`, `FROM`, `WHERE`)
- **Indentation**: Align clauses for readability
- **Parameters**: Use parameterized queries with `$1`, `$2` syntax

## Schema Patterns

- **Primary keys**: Use `{table}_id` pattern with `GENERATED BY DEFAULT AS IDENTITY`
- **Foreign keys**: Use `{table}_id` naming convention consistently
- **Timestamps**: Use `create_date TIMESTAMP(3) NOT NULL DEFAULT NOW()`
- **Booleans**: Use `BOOL DEFAULT false/true` with semantic names

## ID Conventions

**Critical distinction**: UUIDs are used ONLY for specific cases:

**UUIDs (CHAR(36))**:
- **S3 stored images**: `profile_picture_uuid`, `image_uuids` (comma-separated list)
- **Sessions**: `session_uuid` for stateless client identification
- **Reset tokens**: `token_uuid` for secure password reset links

**Auto-incrementing INTEGERs** (everything else):
- **Users**: `user_id`
- **Posts**: `post_id`  
- **Replies**: `reply_id`
- **Messages**: `message_id`
- **Conversations**: `conversation_id`
- **All other entities**

**Rationale**: UUIDs prevent enumeration attacks for S3 images and provide session security. Integers are more efficient for all internal references and relationships.

## Query Style

**Parameterized queries**: Always use `$1`, `$2` syntax for safety:
```sql
SELECT * FROM posts WHERE post_id = $1 AND user_id = $2
```

**JOIN formatting**: Align clauses for readability:
```sql
SELECT p.*, u.display_name
FROM posts p
LEFT JOIN users u ON u.user_id = p.user_id  
WHERE p.create_date > $1
ORDER BY p.create_date DESC
```

## Data Type Conventions

- **IDs**: `INT GENERATED BY DEFAULT AS IDENTITY` or `CHAR(36)` for UUIDs
- **Timestamps**: `TIMESTAMP(3)` with `DEFAULT NOW()` for precision
- **Text fields**: Use specific `VARCHAR(n)` limits:
  - Display names: `VARCHAR(50)`
  - Post titles: `VARCHAR(140)`
  - Post bodies: `VARCHAR(8000)`
- **Booleans**: `BOOL DEFAULT false` with semantic names

## Index Naming

```sql
-- Pattern: idx_{table}_{columns}
CREATE INDEX idx_posts_user_id_create_date ON posts(user_id, create_date)
CREATE INDEX idx_notifications_user_id_read ON notifications(user_id, read)
```
